Formulas

MTTA = Σ(ack time − alert time) / incidents
MTTR = Σ(restore time − ack/detect time) / incidents
MTBF = average time between failures (system reliability, not response speed)
Error budget = 100% − SLO · e.g. 99.9% SLO → 0.1% budget

ITIL glossary, fast

Incident Mgmt — restore service fast, workaround is fine
Problem Mgmt — find & fix root cause, prevent recurrence
Change Enablement (v4) / Change Mgmt (v3) — standard / normal (CAB) / emergency
KEDB — known error database: root cause + workaround, searched first
CAB — Change Advisory Board, reviews higher-risk normal changes
RCA / Five Whys — blameless, iterate to systemic causes not "who"
